# Chandru & Sandhiya — Wedding Invitation

A responsive, cinematic React + TypeScript wedding invitation for Chandru (groom) and Sandhiya (bride), built with Vite, Framer Motion, and Lucide icons.

## Run locally

- `npm install`
- `npm run dev`
- `npm run build` to create a production build in `dist/`
- `npm run preview` to preview the production build
